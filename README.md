# Coasteminder
A coaster but when you set your drink down, it open spotlight search and types "KEEP DRINKING". I made so I don't forget to drink my water while locking in. Uses MX Cherry keys and a seeeduino xiao rp2040.
## Assembly:
Take the pcb and use the through hole components to solder the seeeduino and the switch
<br></br>
Put the top on the switches and put the cover around everything
<br></br>
Put the keycap on
<br></br>
Here is a video: https://youtube.com/shorts/zYlzpWiB-x4?feature=share

## Flashing:
To flash the firmware, press the bott button and while holding it press the reset button
<br></br>
You should see a drive called RP1-RP2
<br></br>
Drag the uf2 file into the drive
<br></br>
Now you should see a drive called CIRCUITPY
<br></br>
Delete everything in there and replace it with everything in the code folder so it looks like this:
